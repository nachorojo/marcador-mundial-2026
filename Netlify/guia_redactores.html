Guía del Marcador en Directo

Cómo insertar y actualizar el marcador del Mundial en artículos y directos de ondacero.es

1

¿Qué es y cómo funciona?

El marcador es una pequeña pieza web (un widget) que se embebe en cualquier artículo del CMS mediante un código iframe. Muestra en tiempo real los equipos, banderas, marcador, fase y estadio.

2

Insertar el marcador en el CMS

1
Abre el editor de Netlify

Ve a marcador-directo-mundial2026.netlify.app/editor.html

2
Selecciona la fecha y el partido

Usa los desplegables para elegir el día y, si ese día hay varios partidos, cuál es el tuyo. El preview se actualiza al instante.

💡 Fíjate en el preview

A la derecha del formulario verás el marcador tal como quedará en la web. Si el partido aún no ha empezado, mostrará la hora. Si ya tiene resultado, lo mostrará.

3
Copia el código generado

Debajo del preview aparecen dos códigos. Copia el que necesites según el campo del CMS:

📄 Código Normal → campo HTML del CMS

Para artículos y directos normales. Se ve como un bloque con <style> + <iframe>.

⚡ Código AMP → campo HTML AMP del CMS

Para la versión AMP del artículo. Usa <amp-iframe>. Si el CMS tiene campo específico AMP, pega este.

4
Pega el código en el artículo

En el CMS, abre el artículo del directo y pega el código en el campo HTML (o HTML AMP según corresponda). Guarda y publica.

⚠️

No copies solo la URL del iframe — copia siempre el bloque completo que genera el editor (incluye los estilos <style> necesarios para que se vea bien en todas las columnas).

📐 Aspecto visual del código HTML que debes pegar
/* estilos que adaptan el alto según la columna */ <style>.mb-mw26{width:100%;height:100px;margin-bottom:15px} div[class*="-8"] .mb-mw26, div[class*="-4"] .mb-mw26, .raiSkinDesktop .mb-mw26{height:132px} @media(max-width:1024px){.mb-mw26{height:131px}}</style> /* el iframe · solo cambia id= y numero= para cada partido */ <iframe class="mb-mw26" src="https://marcador-directo-mundial2026.netlify.app/marcador_v5b.html?id=2026-06-15&numero=3" frameborder="0" allowfullscreen></iframe>

Los dos únicos valores que cambian entre partidos son id (fecha) y numero (nº de partido del día, empezando en 1).

3

Durante el partido — actualizar el marcador

📋 El flujo de trabajo

El marcador no se actualiza solo. Cada vez que hay un gol o cambia el estado del partido, el redactor tiene que actualizar el código en el CMS. El proceso es rápido: menos de un minuto.

1
Abre el editor de Netlify

Selecciona la fecha y el partido. Verás el marcador tal como está ahora.

2
Actualiza los datos

Cambia el Estado y los Goles según el momento del partido. Opcionalmente añade goleadores o penaltis.

Estados disponibles
EstadoCuándo usarlo
ProgramadoAntes de que empiece
1ª PartePrimer tiempo en juego
2ª ParteSegundo tiempo en juego
Prórroga 1ª / 2ªSi hay prórroga
PenaltisTanda de penaltis
FinalizadoPartido terminado
3
Pulsa "↻ Actualizar preview y códigos"

Se genera el nuevo código con los datos actualizados.

4
Copia y pega en el CMS sustituyendo el código anterior

Edita el artículo del directo, borra el bloque HTML del marcador y pega el nuevo. Guarda y publica.

⚡

Truco rápido: Si solo cambia el resultado, puedes editar directamente el número en la URL del iframe en el CMS sin pasar por el editor. Por ejemplo, cambia &gL=0 por &gL=1 para meter un gol local. Ver sección 6 para todos los parámetros.

4

Con qué frecuencia actualizar

📅 Momentos clave para actualizar el marcador
  • Antes del partido — pega el código inicial en el CMS (estado: Programado)
  • Al arrancar el partido — actualiza a "1ª Parte", goles a 0-0
  • Cada gol — actualiza el marcador con el nuevo resultado
  • Descanso / 2ª parte — actualiza el estado
  • Si hay prórroga o penaltis — actualiza el estado y el resultado
  • Al terminar — actualiza a "Finalizado" con el resultado definitivo
⚠️

No es necesario actualizarlo cada minuto. Los lectores entienden que un marcador en una web de radio no es un ticker en tiempo real. Lo importante es que los goles aparezcan y que el estado final (Finalizado + resultado) esté correcto.

5

Cambiar otros datos del marcador

El marcador toma automáticamente del calendario: equipos, banderas, grupo/fase, estadio y hora. Pero si algo falla o hay un cambio de última hora (estadio, horario…), puedes sobreescribirlo añadiendo parámetros a la URL.

Ejemplo: cambiar el estadio en la URL
src="https://marcador-directo-mundial2026.netlify.app/marcador_v5b.html ?id=2026-06-15 &numero=3 &estadio=SoFi+Stadium+%C2%B7+Los+%C3%81ngeles"

Los espacios se escriben como + y los caracteres especiales (ñ, tildes, ·) deben codificarse en URL. El editor lo hace automáticamente.

💡

Forma fácil: En el editor de Netlify rellena el campo Estadio con el nuevo nombre → pulsa Actualizar → copia el código generado. Listo, no tienes que codificar nada a mano.

6

Referencia rápida de parámetros

Todos los parámetros van en la URL del iframe, después de ?, separados por &.

Parámetro Para qué sirve Ejemplo
id= obligatorio Fecha del partido id=2026-06-15
numero= obligatorio Nº de partido del día (1, 2, 3…) numero=3
estado= opcional Estado del partido estado=finalizado
gL= opcional Goles del equipo local gL=2
gV= opcional Goles del equipo visitante gV=1
pL= y pV= opcional Penaltis (los dos juntos) pL=4&pV=5
golL= opcional Goleadores local (URL-encoded) golL=Morata+23%27
golV= opcional Goleadores visitante (URL-encoded) golV=Muller+12%27
minuto= opcional Minuto en juego minuto=34%27
estadio= opcional Nombre del estadio (URL-encoded) estadio=MetLife+Stadium
Valores de estado=

programado · primera-parte · segunda-parte · prorroga-primera · prorroga-segunda · penaltis · finalizado

Ejemplo completo con resultado manual
src=".../marcador_v5b.html?id=2026-06-15&numero=3&gL=3&gV=0&estado=finalizado&golL=Yamal+23%27%2C+Morata+67%27"

→ España 3-0 Cabo Verde · Finalizado · Goleadores: Yamal 23', Morata 67'

⚠️

Apostrofes y comas en goleadores — la comilla del minuto (') se escribe %27 en la URL, y la coma (,) se escribe %2C. El editor de Netlify lo hace solo.
